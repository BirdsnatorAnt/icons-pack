Що робить setup.exe

1

Бере DLL

Поруч із setup.exe лежить icons.dll. Якщо його немає — він вбудований у сам setup.exe, тож вистачить одного файлу.

2

Кладе в System32

Після підтвердження та запиту UAC файл копіюється у C:\Windows\System32\icons.dll.

3

Прибрати

Той самий файл видаляє DLL одним рядком: setup.exe /uninstall.

Як дістати іконку з DLL

/* за назвою (регистр не важливий) */
HMODULE dll  = LoadLibraryW(L"icons.dll");
HICON    icon = (HICON)LoadImageW(dll, L"accessibility",
                                  IMAGE_ICON, 48, 48, LR_DEFAULTCOLOR);

/* або за номером: 0..649 */
ExtractIconExW(L"C:\\Windows\\System32\\icons.dll", 0, NULL, &icon, 1);

Назви ресурсів — це імена файлів без розширення (accessibility, recycle_bin_empty, ms-dos). Порівняння без урахування регістру.
